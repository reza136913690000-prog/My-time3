# زمان من

پروژه منبع یک MVP قابل توسعه برای Android 10 به بالا (minSdk 29) با Kotlin، Jetpack Compose و Room است. عنوان برنامه «زمان من» است و بسته آن `ir.zamaneman.app` می‌باشد.

## ساخت و اجرا

1. پروژه را در Android Studio جدید باز کنید.
2. Gradle Sync را اجرا کنید و یک دستگاه Android 10 یا جدیدتر انتخاب کنید.
3. Run را بزنید. برای Android 13 و بالاتر اجازه اعلان را تأیید کنید.

این فایل ZIP، پروژه منبع است و APK از پیش ساخته شده نیست. ساخت APK به Android Studio/Gradle و دریافت وابستگی‌ها نیاز دارد؛ این محیط build واقعی اندروید را اجرا نکرده و بنابراین قابلیت کامپایل نهایی تأیید نشده است.

## امکانات MVP

شش بخش اصلی با فهرست، جستجو، افزودن، ویرایش و حذف دارند و داده‌ها در Room ذخیره می‌شوند. تاریخ و زمان با DatePicker اندروید انتخاب می‌شود و نمایش تاریخ شمسی و ارقام فارسی است. جلسه‌ها و امور شخصی امکان یادآوری دارند؛ آلارم با AlarmManager و `setAndAllowWhileIdle` تنظیم می‌شود و کانال اعلان ساخته می‌شود. رفتار آلارم دقیق ممکن است به تنظیمات باتری و مجوزهای نسخه اندروید وابسته باشد.

تنظیمات فعلی شامل تهیه فایل پشتیبان JSON و پاک‌سازی داده است. کد Exporter تولید XLSX ساده و PDF با PdfDocument را فراهم می‌کند، اما در رابط کاربری به گردش‌کار ذخیره/اشتراک‌گذاری متصل نشده است. بازیابی JSON، PIN، انتخاب پوسته، انتخاب سفارشی زمان یادآوری و مجوز دقیق آلارم در تنظیمات هنوز پیاده‌سازی نشده‌اند؛ برخی مشخصات در فرم‌ها به فیلدهای مشترک نگاشت شده‌اند. این موارد برای انتشار محصول باید تکمیل و آزمایش شوند.
